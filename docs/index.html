Projet cybersécurité · EMBER2024

Reconnaître une famille de malware, sans l'exécuter.

Un modèle scikit-learn lit les caractéristiques statiques d'un fichier Windows (en-têtes, imports, sections, octets) et en déduit sa famille. Aucun exécutable n'est téléchargé ni lancé : tout part des features d'EMBER2024.

Et si la famille était inconnue ?

Le modèle range toujours un fichier dans l'une de ses familles. Avec un seuil, il répond « inconnue » quand il hésite : il répond moins souvent, mais se trompe moins.

Importance des features

Ce sur quoi le modèle s'appuie.

Baisse du F1 macro quand on mélange toutes les colonnes d'un groupe entre les fichiers du test : plus la baisse est forte, plus le modèle dépend de ce groupe.

Méthode

Comment nous avons procédé.

01

Les données

EMBER2024 : des millions de fichiers Windows déjà réduits à 2 568 caractéristiques. Les 10 familles les plus fréquentes, un découpage dans le temps.

02

Le modèle

Plusieurs modèles d'arbres comparés sur les semaines les plus récentes du train ; le meilleur est évalué une seule fois sur le test.

03

L'explication

Permutation des groupes de features, SHAP fichier par fichier, et vrais noms des colonnes hachées.

04

L'éthique

Aucun exécutable téléchargé ni lancé, des empreintes qui servent seulement d'identifiants, un outil d'aide et pas de décision automatique.

Outil d'aide au tri, pas de décision automatique. Le modèle ne connaît que 10 familles de fichiers Win32 : dans le test réel, 58 % des malwares appartiennent à d'autres familles.
